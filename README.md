# claude-task-bar

複数の Claude セッションの「終わった／まだ動いてる」を一目で分かるようにする、Windows 常駐（システムトレイ）アプリ。

## 何を解決するか

IDE・ターミナル・claude.ai(web)・Claude in Chrome・Claude Desktop で Claude を同時に走らせていると、
どのセッションが応答／推論を終えたのか分からず、いちいち全部を見に行くことになる。

claude-task-bar は各セッションの完了を監視し、終わった瞬間にマスコットが画面端からスライドして
「終わったよー」と知らせる。マスコットをクリックすると、そのセッションのウィンドウ／タブに即ジャンプする。

## 全体構成

5つの利用面 → 3種のアダプタ → 中央の常駐アプリ → マスコット表示＆フォーカス制御。

| 利用面 | 検知方法（アダプタ） | 実現手段 |
|---|---|---|
| Claude Code（IDE） | Stop フック | 応答完了時にコマンド実行 → ローカルへ通知 |
| Claude Code（ターミナル） | Stop フック | 同上（settings のフック） |
| claude.ai（web） | ブラウザ拡張 | DOM 監視で生成停止を検知 → ローカルへ通知 |
| Claude in Chrome | ブラウザ拡張 | 同上 |
| Claude Desktop | OS 通知リスナー | Windows UserNotificationListener で通知取得 |

中央アプリはローカルの受信口（HTTP 等）でイベントを受け、
セッション台帳（どのウィンドウ／タブか）を保持する。

## 技術スタック

- .NET / C#（Windows 専用）
- システムトレイ常駐：NotifyIcon
- マスコットのオーバーレイ：WPF の透明・最前面ウィンドウ（クリックスルー）
  - アニメーションを作り込むため、オーバーレイ内に **WebView2** を埋め込み、
    マスコット描画は HTML/CSS/Canvas 側で行う構成を想定
- イベント受信：ローカル HTTP（HttpListener など、ポートは設定可能）
- ウィンドウ／タブへのフォーカス：Win32 SetForegroundWindow（＋拡張連携でタブ切替）
- デスクトップ通知の取得：Windows.UI.Notifications.Management.UserNotificationListener

## マスコット仕様（確定）

Claude のスパーク（放射状バースト）をモチーフにしたドット絵キャラ。

- **モチーフ**：Claude スパーク。中央のコア ＋ 12 方向のトゲ（長短を交互）
- **配色**：テラコッタ × 生成り
  - コア：`#e6926a`（中心ハイライト）／`#c96442`（本体）／`#a94e33`（リム）
  - トゲ：`#c96442`、先端は金 `#f4b25e`（チカチカ点滅）
  - 顔：目 `#2a1712` ＋ 白ハイライト、口 `#6e3320`
  - 背景（生成り）：`#efe7d9`、吹き出し：`#faf6ee`／枠 `#7a3b28`
- **表情**：つぶら目 ＋ スマイル、一定間隔でまばたき
- **出現**：画面端から「ぬるっと」スライドイン（イージングで柔らかく着地）
- **アイドル**：1 ドット単位のカクカク上下（8bit 風）＋ トゲ先端の点滅
- **クリック**：ぴょんと跳ねて退場（＝ 該当セッションへジャンプ）
- **通知表示**：吹き出し「終わったよー！」＋ どのセッションかを示すチップ（IDE / ターミナル / web …）
